    Le menu scrollable¶

    Le problème à résoudre¶

    10 jeux à afficher. Écran de 135px de hauteur. Chaque item de menu occupe 24px. Calcul :

    10 jeux × 24px = 240px nécessaires
Écran disponible = 135px
Débordement : 105px → environ 4 jeux cachés

    Il est impossible d'afficher toute la liste d'un coup. Il faut un système de fenêtre glissante : on affiche seulement une portion de la liste, et cette fenêtre se déplace quand le curseur approche d'un bord.

    Le concept : deux variables suffisent¶

    curseur      ← index du jeu sélectionné (0 à 9)
décalage     ← index du premier jeu affiché à l'écran
VISIBLE = 4  ← nombre de jeux affichés simultanément

Fenêtre visible = jeux[décalage  …  décalage + VISIBLE - 1]

    Analogie : C'est exactement comme faire défiler vos contacts sur un téléphone. La liste entière existe déjà "sous" l'écran, mais vos yeux ne voient que la petite portion que l'écran autorise. On appelle cela une fenêtre glissante.

    Illustration pas à pas¶

    • État initial — curseur = 0, décalage = 0
    ↑  (rien au-dessus)
▶  [0] Snake       ← sélectionné
   [1] Morpion     ← visible
   [2] Pong        ← visible
   [3] Breakout    ← visible
↓  plus bas...
   [4] Flappy      ← caché
   [5] Tetris      ← caché
   ...
    • Après 1 appui BAS — curseur = 1, décalage = 0 (fenêtre ne bouge pas)
    ↑  (rien au-dessus)
   [0] Snake
▶  [1] Morpion     ← sélectionné
   [2] Pong
   [3] Breakout
↓  plus bas...
    • Après 4 appuis BAS — curseur = 4, décalage = 1 (fenêtre glisse !)
    ↑  plus haut...
   [0] Snake       ← caché maintenant
   [1] Morpion
   [2] Pong
   [3] Breakout
▶  [4] Flappy      ← sélectionné
↓  plus bas...

    La fenêtre a glissé d'un cran : décalage est passé de 0 à 1.

    Algorithme complet¶

    naviguer_bas() :
  curseur ← curseur + 1

  si curseur ≥ total_jeux :               // dépassement : revenir au début
    curseur  ← 0
    décalage ← 0                          // fenêtre repart en haut

  sinon si curseur ≥ décalage + VISIBLE : // curseur sort par le bas
    décalage ← curseur - VISIBLE + 1      // faire glisser la fenêtre vers le bas


naviguer_haut() :
  curseur ← curseur - 1

  si curseur < 0 :                        // dépassement : aller à la fin
    curseur  ← total_jeux - 1
    décalage ← max(0, total_jeux - VISIBLE)  // fenêtre va tout en bas

  sinon si curseur < décalage :           // curseur sort par le haut
    décalage ← curseur                   // faire remonter la fenêtre

    La condition de glissement expliquée¶

    La fenêtre ne bouge que si le curseur en sort. Tant que le curseur reste à l'intérieur de [décalage … décalage + VISIBLE - 1], la fenêtre est fixe.

    Fenêtre : [décalage=2 … décalage+VISIBLE-1=5]
Jeux visibles : [2][3][4][5]

curseur = 3 → dans la fenêtre → décalage inchangé
curseur = 5 → bord bas → décalage inchangé (encore dans la fenêtre)
curseur = 6 → sort par le bas → décalage ← 6 - 4 + 1 = 3
              Nouvelle fenêtre : [3][4][5][6]

    Le wrap circulaire¶

    Quand on dépasse le dernier item en allant vers le bas, on revient au premier — et vice versa. Il faut impérativement resynchroniser décalage lors du wrap, sinon la fenêtre reste en bas alors que le curseur est revenu en haut.

    // ✅ Correct
si curseur ≥ total_jeux :
  curseur  ← 0
  décalage ← 0     ← fenêtre aussi repart en haut

// ❌ Incohérence visuelle
si curseur ≥ total_jeux :
  curseur ← 0      ← curseur en haut
                   ← décalage reste en bas → Snake affiché au milieu d'une liste vide

    Le debounce de navigation¶

    La navigation utilise un timer de 200ms pour éviter de défiler trop vite quand le bouton est maintenu. Voir la section Timing Non-Bloquant pour le principe général.

    si bouton_bas.pressé ET (maintenant - dernière_navigation > 200ms) :
  naviguer_bas()
  dernière_navigation ← maintenant

    Affichage de la fenêtre¶

    afficher() :
  si NON needsRedraw : retour

  pour i de 0 à VISIBLE - 1 :
    idx ← décalage + i               // index réel dans la liste

    si idx ≥ total_jeux : arrêter    // plus de jeux à afficher

    y ← zone_titre + (i × hauteur_item)

    si idx == curseur :
      // Item sélectionné : fond coloré + flèche
      dessiner_fond_sélection(y)
      dessiner_texte(jeux[idx].nom, y, couleur_sélection)
    sinon :
      // Item normal : texte gris
      dessiner_texte(jeux[idx].nom, y, couleur_normale)

  // Indicateurs de scroll
  si décalage > 0 :
    dessiner_indicateur_haut("▲ plus haut")
  si décalage + VISIBLE < total_jeux :
    dessiner_indicateur_bas("▼ plus bas")

    À retenir¶

    • Deux variables pilotent tout : curseur (où je suis) et décalage (ce que je vois).
    • La fenêtre ne glisse que quand le curseur en sort — jamais avant.
    • Le wrap circulaire doit resynchroniser décalage en même temps que curseur.
    • Les indicateurs ▲ et ▼ informent le joueur que la liste continue.
