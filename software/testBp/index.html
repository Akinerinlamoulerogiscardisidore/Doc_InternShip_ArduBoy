    Test des boutons¶

    Avant de lancer un jeu, il est crucial de s'assurer que chaque bouton est correctement câblé et reconnu par notre ESP 32. Pour cela, nous utilisons une configuration spécifique appelée INPUT_PULLUP pour pouvoir éviter l'effet d'anti-rebond.

    Comprendre le fonctionnement (Pull-up interne)¶

    Nous n'utilisons pas de résistances internes pour la configuration pull-up interne car notre carte en possède déjà des résistances de PULLUP intégrées que nous pourrons activer par code.

    Comment cela marche ?

    • Bouton relâché : La résistance interne "tire" le signal vers le 3.3V. L'ESP32 lit un état HAUT (1).

    • Bouton appuyé : Le courant passe par le bouton vers la masse (GND). L'ESP32 lit un état BAS (0).

    C'est ce qu'on appelle de la logique inversée :

    Appuyé = 0 (false) Relâché = 1 (true)

    Pour simplifier le code de nos jeux, nous utilisons l'opérateur d'inversion ! (NON) :

    bool boutonAppuye = !digitalRead(PIN);

    (Ainsi, si on lit 0, la variable devient "true")

    Le programme de test¶

    Ce programme affiche en temps réel quel bouton est appuyé sur l'écran de la console. Cela représente un outil de diagnostic idéal pour vérifier l'état des boutons poussoirs.

    Voici le code:

    #include <TFT_eSPI.h>

#define BTN_UP    25
#define BTN_DOWN  26
#define BTN_LEFT  27
#define BTN_RIGHT 32
#define BTN_A     33
#define BTN_B     15

TFT_eSPI screen = TFT_eSPI();

void setup() {
  Serial.begin(115200);

  pinMode(BTN_UP,    INPUT_PULLUP);
  pinMode(BTN_DOWN,  INPUT_PULLUP);
  pinMode(BTN_LEFT,  INPUT_PULLUP);
  pinMode(BTN_RIGHT, INPUT_PULLUP); 
  pinMode(BTN_A,     INPUT_PULLUP);
  pinMode(BTN_B,     INPUT_PULLUP);

  screen.init();
  screen.setRotation(1);
  screen.fillScreen(TFT_BLACK);

  screen.setTextColor(TFT_CYAN, TFT_BLACK);
  screen.setTextSize(2);
  screen.setCursor(30, 55);
  screen.print("Appuie un bouton !");
}

void loop() {
  bool up    = !digitalRead(BTN_UP);
  bool down  = !digitalRead(BTN_DOWN);
  bool left  = !digitalRead(BTN_LEFT);
  bool right = !digitalRead(BTN_RIGHT);
  bool a     = !digitalRead(BTN_A);
  bool b     = !digitalRead(BTN_B);

  // Effacer la zone d'affichage
  screen.fillRect(0, 40, 240, 60, TFT_BLACK);

  // Repositionner le curseur ← AJOUTÉ
  screen.setTextSize(3);
  screen.setCursor(80, 55);

  // Couleur selon le bouton
  if (up)    screen.setTextColor(TFT_GREEN,    TFT_BLACK);
  if (down)  screen.setTextColor(TFT_RED,      TFT_BLACK);
  if (left)  screen.setTextColor(TFT_CYAN,     TFT_BLACK);
  if (right) screen.setTextColor(TFT_YELLOW,   TFT_BLACK);
  if (a)     screen.setTextColor(TFT_ORANGE,   TFT_BLACK);
  if (b)     screen.setTextColor(TFT_WHITE,    TFT_BLACK);

  // Afficher le nom du bouton
  if      (up)    screen.print("HAUT");
  else if (down)  screen.print("BAS");
  else if (left)  screen.print("GAUCHE");
  else if (right) screen.print("DROITE");
  else if (a)     screen.print("A");
  else if (b)     screen.print("B");
  else {
    screen.setTextColor(TFT_DARKGREY, TFT_BLACK);
    screen.print("...");
  }

  delay(50);  // réduit à 50ms
}
    Il permettra lors de l'appui sur un bouton pousssoir de vérifier s'il est vraiment connecté ou pas.

    Diagnostic de maintenance

    Si un bouton ne réagit pas lors du test, vérifiez la masse (GND) : une des pattes de chaque bouton doit être reliée au rail commun GND. Si le problème ne se retrouve pas là, assurez-vous que le fil est planté dans le bon port.

    Pour en savoir plus sur le bouton poussoir, consultez le lien Pour en savoir plus sur le bouton poussoir.

    C'est tout pour ce tuto de test.
