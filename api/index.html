    API Reference¶

    Référence complète de l'API pour développer des jeux sur la console Arduboy ESP32.

    Cette API est basée sur la bibliothèque TFT_eSPI pour l'affichage et des classes personnalisées pour la gestion des boutons et des jeux. Tous les exemples sont en C++ pour Arduino IDE.

    Classe Game¶

    Classe de base abstraite pour tous les jeux. Chaque jeu doit hériter de cette classe et implémenter les méthodes virtuelles pures.

    Constructeur¶

    Game(TFT_eSPI* tft);
    • Paramètres : tft c'est le pointeur vers l'instance TFT_eSPI pour l'affichage.
    • Description : Initialise le jeu avec l'écran TFT.

    Méthodes virtuelles pures (à implémenter)¶

    void initialiser()¶

    Remet le jeu à son état initial (score à 0, positions de départ, etc.).

    void mettreÀJour(Buttons& boutons)¶

    Met à jour la logique du jeu en fonction des entrées.

    • Paramètres : boutons c'est la structure contenant l'état des boutons (voir ci-dessous).

    void afficher()¶

    Dessine l'état actuel du jeu sur l'écran. Utilise le rendu différentiel pour éviter le scintillement.

    bool estTerminé()¶

    • Retour : true si la partie est finie, false sinon.

    int obtenirScore()¶

    • Retour : Le score actuel du joueur.

    Structure Buttons¶

    Représente l'état des boutons physiques de la console.

    struct Buttons {
    bool up, down, left, right, a, b;  // État maintenu (true si appuyé)
    bool upPressed, downPressed, leftPressed, rightPressed, aPressed, bPressed;  // Front montant (true une fois par appui)
};
    • up/down/left/right/a/b : true tant que le bouton est maintenu appuyé.
    • upPressed/etc. : true uniquement au moment de l'appui (détection de front montant).

    Utilisation

    Utilisez boutons.up pour des mouvements continus (ex. : déplacer une raquette). Utilisez boutons.upPressed pour des actions ponctuelles (ex. : tourner une pièce dans Tetris).

    Fonctions d'affichage (wrappers TFT_eSPI)¶

    Ces fonctions simplifient l'affichage en utilisant le rendu différentiel.

    void dessinerRect(int x, int y, int largeur, int hauteur, uint16_t couleur)¶

    Dessine un rectangle plein. - Paramètres : - x, y : Position en pixels (coin supérieur gauche). - largeur, hauteur : Dimensions. - couleur : Couleur RGB565 (ex. : TFT_BLACK, TFT_WHITE).

    void effacerRect(int ancienneX, int ancienneY, int largeur, int hauteur)¶

    Efface un rectangle (le peint en noir) pour le rendu différentiel. - Utilisation : Appelez avant de redessiner un objet déplacé.

    void afficherTexte(int x, int y, const char* texte, uint16_t couleur = TFT_WHITE, int taille = 2)¶

    Affiche du texte. - Paramètres : - x, y : Position. - texte : Chaîne à afficher. - couleur : Couleur du texte. - taille : Taille de police (1-4).

    Couleurs

    Utilisez les constantes TFT_eSPI : TFT_RED, TFT_GREEN, TFT_BLUE, etc. Pour des couleurs personnalisées, convertissez en RGB565 avec tft.color565(r, g, b).

    Fonctions audio (Buzzer)¶

    void jouerNote(int frequence, int dureeMs)¶

    Joue une note sur le buzzer passif. - Paramètres : - frequence : Fréquence en Hz (ex. : 440 pour La). - dureeMs : Durée en millisecondes.

    void arreterSon()¶

    Arrête immédiatement la lecture audio.

    Buzzer passif

    Le buzzer doit être passif pour jouer des fréquences variables. Un buzzer actif ne joue que des sons fixes.

    Exemple d'utilisation¶

    Voici un exemple simple pour un jeu basique (boule qui rebondit) :

    #include "Game.h"

class MonJeu : public Game {
private:
    int posX = 10, posY = 10;
    int anciennePosX, anciennePosY;
    int vitesseX = 2, vitesseY = 1;

public:
    MonJeu(TFT_eSPI* tft) : Game(tft) {}

    void initialiser() override {
        posX = 10; posY = 10;
        score = 0;
    }

    void mettreÀJour(Buttons& boutons) override {
        anciennePosX = posX;
        anciennePosY = posY;
        posX += vitesseX;
        posY += vitesseY;

        // Rebonds sur les bords
        if (posX <= 0 || posX >= 135) vitesseX = -vitesseX;
        if (posY <= 0 || posY >= 240) vitesseY = -vitesseY;

        if (boutons.aPressed) score++;  // Incrémenter score sur appui A
    }

    void afficher() override {
        effacerRect(anciennePosX, anciennePosY, 10, 10);
        dessinerRect(posX, posY, 10, 10, TFT_RED);
        afficherTexte(0, 0, String("Score: " + String(score)).c_str());
    }

    bool estTerminé() override { return false; }  // Jeu infini
    int obtenirScore() override { return score; }
};

    Extension

    Pour ajouter de nouvelles fonctions, modifiez la classe Game ou créez des helpers dans un fichier séparé. Assurez-vous de respecter le contrat pour la compatibilité avec la boucle principale.
