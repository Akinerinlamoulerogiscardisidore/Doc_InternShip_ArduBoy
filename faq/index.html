    FAQ¶

    Foire aux questions sur la réalisation et la programmation de la console Arduboy ESP32.

    Hardware¶

    Ecran noir¶

    L'écran reste noir après le câblage. Que faire ?

    • Vérifiez que vous aviez effectuez les configurations logicielles Configuration.
    • Assurez-vous que la tension d'alimentation est correcte (3.3V pour l'ESP32). Un voltage trop bas peut causer un écran noir.
    • Testez avec un sketch simple TFT_eSPI (ex. : TFT_Hello_World) pour isoler le problème.

    Buzzer silencieux¶

    Le buzzer ne fait aucun son. Pourquoi ?

    • Vérifiez si le buzzer est passif (nécessaire pour jouer des fréquences variables comme des notes de musique). Un buzzer actif ne joue que des sons fixes.
    • Contrôlez le câblage : le buzzer doit être connecté à une broche PWM (ex. : GPIO 12). Utilisez tone(pin, frequency) pour tester.
    • Si le son est faible, ajoutez un transistor pour amplifier le signal.

    Boutons répondant pas¶

    Les boutons ne répondent pas. Comment déboguer ?

    • Vérifiez la masse commune : tous les boutons doivent être reliés au GND de l'ESP32.
    • Testez chaque bouton individuellement avec un multimètre en mode continuité.
    • Dans le code, utilisez digitalRead(pin) pour vérifier l'état. Les boutons sont normalement HIGH (relâchés) et LOW (appuyés) avec une résistance pull-up.

    Image à l'envers¶

    L'écran affiche l'image à l'envers ou tournée. Comment corriger ?

    • Dans TFT_eSPI, utilisez tft.setRotation(angle) où angle est 0, 1, 2 ou 3 (0 = portrait normal).
    • Ajoutez cette ligne dans setup() de votre sketch : tft.setRotation(1); pour tourner de 90°.

    Software¶

    "ESP not found"¶

    Erreur : "ESP32 not found" lors de la compilation. Que faire ?

    • Vérifiez que le bon gestionnaire de cartes est installé (ESP32 v3.3.7 ou plus récent) via Outils > Gestionnaire de cartes.
    • Sélectionnez la carte correcte : "ESP32 Dev Module" ou "TTGO T1" dans Outils > Type de carte.
    • Assurez-vous que le port COM est correct (Outils > Port). Redémarrez l'IDE Arduino si nécessaire.

    Configurer TFT_eSPI¶

    Comment configurer TFT_eSPI pour l'ESP32 TTGO T-Display ?

    • Dans le dossier Arduino/libraries/TFT_eSPI, ouvrez User_Setup_Select.h.
    • Commentez la ligne #include <User_Setup.h> (ajoutez // au début).
    • Décommentez la ligne #include <User_Setups/Setup25_TTGO_T_Display.h>.
    • Redémarrez l'IDE Arduino. Cela définit les bonnes broches pour l'écran TFT.

    Librairie non trouvé¶

    L'IDE Arduino ne trouve pas la bibliothèque TFT_eSPI. Solution ?

    • Allez dans Croquis > Inclure une bibliothèque > Gérer les bibliothèques.
    • Recherchez "TFT_eSPI" et installez la version 2.5.43 ou plus récente.
    • Si elle n'apparaît pas, téléchargez le ZIP depuis GitHub et installez-le manuellement via Croquis > Inclure une bibliothèque > Ajouter un fichier .ZIP.

    Programme non compilé¶

    Le programme compile mais ne se téléverse pas. Pourquoi ?

    • Vérifiez le câble USB (doit supporter le transfert de données, pas seulement l'alimentation).
    • Sur Windows, installez les drivers CP210x pour l'ESP32 (disponibles sur le site Silicon Labs).
    • Dans l'IDE, sélectionnez le bon port COM. Si "Aucun port série disponible", redémarrez l'ordinateur ou changez de câble.

    Mode debug¶

    Comment activer le mode debug pour voir les erreurs ?

    • Utilisez Serial.begin(115200); dans setup() et Serial.println("Message"); pour afficher des messages.
    • Ouvrez le moniteur série (Outils > Moniteur série) à 115200 bauds pour voir les logs.

    Jeux et programmation¶

    Ajouter un jeu¶

    Comment ajouter un nouveau jeu à la console ?

    • Créez une nouvelle classe héritant de Game (ex. : class MonJeu : public Game).
    • Implémentez les méthodes virtuelles : initialiser(), mettreÀJour(Buttons& boutons), afficher(), estTerminé(), obtenirScore().
    • Dans la boucle principale, ajoutez une condition pour instancier et lancer votre jeu (ex. : dans le menu).
    • Respectez le contrat des jeux pour une intégration fluide.

    Ecran scintillant¶

    Pourquoi l'écran scintille pendant le jeu ?

    • Utilisez le rendu différentiel : sauvegardez l'ancienne position, effacez l'ancien dessin, puis dessinez le nouveau.
    • Évitez tft.fillScreen(TFT_BLACK); à chaque frame, car cela efface tout l'écran et cause un flash noir.
    • Exemple : effacerRect(ancienneX, ancienneY, largeur, hauteur); puis dessinerRect(nouvelleX, nouvelleY, largeur, hauteur, couleur);.

    Gérer les boutons¶

    Comment gérer les boutons : maintenu vs pressé ?

    • boutons.up : vrai tant que le bouton est maintenu (pour mouvements continus, ex. : raquette Pong).
    • boutons.upPressed : vrai uniquement au moment de l'appui (pour actions ponctuelles, ex. : saut, rotation Tetris).
    • La détection de front montant est gérée automatiquement dans la structure Buttons.

    Jeu trop lent¶

    Le jeu est trop lent. Comment optimiser ?

    • Réduisez la résolution d'affichage ou le nombre d'objets dessinés.
    • Utilisez des variables locales au lieu de globales pour éviter les accès mémoire lents.
    • Désactivez les fonctionnalités inutiles de TFT_eSPI (ex. : pas de rotation si pas nécessaire).
    • Mesurez le temps avec millis() pour identifier les goulots d'étranglement.

    Sons personnalisés¶

    Comment jouer des sons personnalisés ?

    • Utilisez jouerNote(frequence, dureeMs); pour des notes individuelles.
    • Pour une mélodie, créez un tableau de fréquences et durées, puis bouclez dessus avec des delay().
    • Exemple : jouerNote(440, 500); pour un La pendant 500ms.

    Général¶

    Où trouver plus d'aide ?¶

    • Consultez les forums Arduino ou ESP32 sur Reddit (r/arduino, r/esp32).
    • Vérifiez la documentation TFT_eSPI sur GitHub pour les fonctions avancées.
    • Pour des exemples de code, regardez les sketches d'exemple dans l'IDE Arduino.

    La console ne démarre pas. Que vérifier en premier ?¶

    • Alimentation : tension correcte (3.3V), polarité respectée.
    • Câblage : vérifiez les connexions avec un multimètre.
    • Code : assurez-vous que setup() et loop() sont présents, et que TFT_eSPI est correctement configuré.
    • Si rien ne fonctionne, testez avec un sketch minimal (ex. : blink LED) pour isoler le problème matériel/logiciel.
